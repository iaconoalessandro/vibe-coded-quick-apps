# Design concepts (parked)

Static mockups of alternative redesigns, kept for later. They are not part of the
site and nothing links to them.

| Folder | Concept | What it is |
|---|---|---|
| `workspace/` | Workspace | App layout: dark sidebar of every calculator, three-panel question screen with a live score, results dashboard with a dot plot against each school's bar. |
| `bento/` | Bento | Pastel tile grid; chunky answer tiles; results sorted into Competitive / Possible / Stretch columns. |
| `minimal/` | Minimal | White and airy; fill-in-the-blanks start, slider questions with "what if" scores, one diverging chart of distance from each bar. |

Each folder has `landing.html`, `wizard.html`, `results.html` and a `board.jpg`
overview. Open the HTML files directly in a browser.

The numbers are real output of the Management model for one sample applicant
(`data.js`). Unlike the site, these mockups load their fonts from Google Fonts,
so they need a network connection to look right.
