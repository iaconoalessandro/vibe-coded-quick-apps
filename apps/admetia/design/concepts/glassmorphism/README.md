# Glassmorphism preview

An isolated visual adaptation of the current Admetia website. The published
design remains The City. All page data and calculators come from the normal
production build; the homepage uses a glass hero and a four-card task grid.

Run `npm run build`, then `node design/concepts/glassmorphism/build-preview.mjs`.
The script prints a temporary output directory. Serve it with a local HTTP
server and open `glass/index.html`. The preview toolbar switches between this
concept and The City on the same page. No preview files are published.
