## Fixes
- Unlocalised permit name (new style rule: English-named permit in a country where English is not official, so translate). atlas-ae.0084, 0096, 0109: "jobseeker visit visa" → "visado de visita para buscar empleo".
- atlas-ae.0093: "En nuestra lectura de los programas abiertos, se pide…" → "Los programas abiertos consultados piden…". Mistranslation: "read" is a participle ("programmes read"), not "our reading".
- atlas-ae.0092: "los traslados" → "por traslado interno" (transfer hiring = hiring by transfer within a group).
- atlas-ae.0090: "becarios" → "becas". "Scholars" is not "interns" (glossary: intern = becario).
- atlas-ae.0082: "ciclos de selección … con fecha límite antes del 1 de febrero" → "ciclos al año para titulados … con solicitudes que deben presentarse antes del 1 de febrero". Removed the added "de selección" and the redundant "fecha límite antes del".
- atlas-ae.0094: "ministerio de Educación/Asuntos Exteriores de los EAU" → "Ministerio…" (named UAE ministries capitalised).
- atlas-ae.0111: "jornada de assessment centre" → "jornada de evaluación" (English says "assessment day", not "assessment centre").
- atlas-ae.0117, 0127: "la biblioteca" → "la biblioteca de fuentes" (glossary).
