# Review: atlas-kr-01 (South Korea guide, part 1)

57 ids compared; 8 edits across 6 ids made. JSON valid, ids and order unchanged. No HTML or placeholders in this chunk.

## Fixes
- atlas-kr.0015: "107,2 billones KRW" -> "107,2 billones de KRW". The value is right (107.2 trillion = 107,2 billones); the "de" was missing, as in the guide's "13,0107 billones de TRY".
- atlas-kr.0026, atlas-kr.0031: "millones ₩" / "billones ₩" -> "millones de ₩" / "billones de ₩" (10,17 / 4,85 millones; 651,4 / 575,0 / 2560,8 / 125,6 / 121,1 billones). The figures are unchanged and were checked against the English; the "de" was added for the same reason as 0015.
- atlas-kr.0022: "Los salarios" -> "Los sueldos", to match "sueldo" in the same string and the "Sueldos por región" heading (0028).
- atlas-kr.0034: "escuelas universitarias" -> "centros universitarios de ciclo corto" for "junior-college". "Escuela universitaria" is the old Spanish three-year diploma school, so it would mislead.
- atlas-kr.0055: "ya habían elegido candidatos" -> "eligieron candidatos". The "ya" added a timing the English does not have.

## Checked, left as is
- Won figures: 0031 (trillion -> billones, 2.560,8 written without a point as a four-digit integer part), 0032 and 0033 (points as thousands separators), 0048 (8500), 0055 and 0056 (2500, 3000).
- 0022 "crowd-sourced ... text proxy": "datos aportados por usuarios ... proxy de texto" is acceptable.
- 0042 "spec" kept in quotation marks.
- "Sólido" (0020), "polo", "vía", "itinerario" and "selección continua" follow the glossary.

## Doubts for a native speaker
- 0034 "centros universitarios de ciclo corto" for Korean junior colleges (2-3 year vocational degrees): there is no established Spanish term.
- 0050 "selección pública a ciegas" (blind public recruitment) could read better as "convocatoria pública a ciegas".
- 0034 "por área" for field of study (area is the glossary term for the 13 career fields).
