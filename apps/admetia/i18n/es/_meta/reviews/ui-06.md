# Review of ui-06 (es-ES)

All 176 ids compared with the source. Tags, hrefs, classes and ids are intact and in order. There are no placeholders or figures to check. Register is tú throughout. 11 edits made.

## Fixes

- Entry pay rendered "sueldo de entrada" (a calque) → "sueldo inicial" (reason: natural Spanish for starting pay)
  - ui.1004: "Sueldo de entrada: EE. UU. / …" → "Sueldo inicial: EE. UU. / …"
  - ui.1055, ui.1063 and ui.1061: same change.
- ui.1015: "(personas, cuant., estrés, …)" → "(personas, cuantitativo, estrés, …)". The style guide says never to abbreviate in running prose.
- ui.1022 and ui.1023: "máster en Ciencias de la computación" / "Ciencia de datos e IA" → lower case "ciencias de la computación" / "ciencia de datos e IA". Spanish does not capitalise subject names, and the neighbouring "máster en marketing" is already lower case.
- ui.1012: "menciona este" → "menciona esta". The referent is "familia de puestos" (feminine), so "este" was ambiguous or wrong.
- ui.0902: "no un consejo" → "no un asesoramiento". This matches the legal-advice sense used in ui.0905 and ui.0954.
- ui.0923: "Sé qué estudié" → "Sé lo que estudié". More natural.
- ui.0998: "el RAL" → "la RAL" (see doubt below).

## Translator's doubts, resolved

- ui.0965 "Cuant." (Quant): kept. The English is already a clipped column header and "Cuant." mirrors it. The style guide forbids abbreviating to fit, so a native speaker should decide whether "Cuantitativo" fits the column.
- ui.0968 and ui.0932 "Acceso" (Entry): kept. It is clear next to "Dificultad de acceso" (ui.0967) and matches that wording.
- add-on / addendum → "anexo": kept in both places. They refer to the same document, so consistency is more useful than distinguishing them.
- RAL: kept as an Italian term, unglossed as in the source.
