# Sistema di Riferimento Unico: Visti e Immigrazione (Admetia)

## Scopo
Questo archivio costituisce l'**UNICA fonte di verità** del progetto Admetia per quanto concerne le normative di ingresso, soggiorno, studio, ricerca, tirocinio, lavoro, fiscalità degli impatriati ed emigrazione per tutti i Paesi trattati.

Nessun dato su visti, permessi di soggiorno, soglie di sussistenza, contributi sanitari o requisiti amministrativi può essere inserito nel codice sorgente (`data/atlas/*.js`), nei modelli runtime o nei file di documentazione/ricerca senza che esso sia presente e verificato all'interno di questa directory.

## Regole di Governance e Integrità
1. **Unicità della Verità:** I file runtime e le pagine del sito devono puntare ai file di questa cartella oppure derivare i propri valori direttamente da essi. È vietata la duplicazione non sincronizzata di dati su visti e permessi altrove.
2. **Standard di Verifica (Gate di Integrità):**
   - Ogni affermazione deve essere supportata da fonte primaria ufficiale con URL specifico (non homepage generiche).
   - Ogni soglia economica, tariffa o termine temporale deve recare il riferimento `[ID-fonte]` univoco consultabile nel file `{paese}_sources.md`.
   - I dati incerti, privi di fonte primaria o soggetti a difformità prasseologiche non possono entrare nella guida come fatti certi, ma devono essere registrati nel file `{paese}_open_questions.md`.
3. **Data di Riferimento e Revisione Periodica:** Tutti i dati riportano la data dell'ultimo audit e una data di scadenza (massimo 6 mesi per parametri volatili quali assegno sociale, soglie di visto studio e cambi consolari).
