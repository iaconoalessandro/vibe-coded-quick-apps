## Regenerating

```bash
npm run careers   # the Career Explorer's pages (also writes the data the figures read)
npm run shell     # the chrome and figures in the root pages
npm test          # 14 suites
npm run build     # _site/
node tools/ux-ledger.js --write
```

## Preview

```bash
python3 -m http.server 8777            # source, at http://localhost:8777/
npm run build && mkdir -p /tmp/pages && rm -rf /tmp/pages/admetia && cp -R _site /tmp/pages/admetia && (cd /tmp/pages && python3 -m http.server 8778)
# built site, at http://localhost:8778/admetia/
```
