## Why this week exists
Everything later (CSV parsing, star schemas, SQL loading) is built from five things: **values, names, conditions, loops, functions**. You know the algorithms. This week is about getting the syntax into your fingers, so writing a loop takes 10 seconds, not 10 minutes.

## Values, types, names
```python
qty = 5            # int
price = 12.5       # float
store = "S1"       # str
active = True      # bool
nothing = None     # "no value", common in dirty data
type(qty)          # <class 'int'>
int("42"), float("2.5"), str(7)   # conversions; int("4.2") raises ValueError
```
A name is a label stuck on an object. `qty = qty + 1` makes a new int and moves the label.

## Strings (immutable: methods return NEW strings)
```python
s = "  Truth Social  "
s.strip().lower()            # 'truth social'
s.split()                    # ['Truth', 'Social']
"-".join(["a", "b"])         # 'a-b'
s[2:7], s[-1], s[::-1]       # slicing: start inclusive, end exclusive
f"{store}: {qty} x {price:.2f} = {qty * price:.2f}"   # 'S1: 5 x 12.50 = 62.50'
```

## Conditions and loops
```python
if qty > 10:
    size = "big"
elif qty > 0:
    size = "small"
else:
    size = "none"

for i in range(3):           # 0, 1, 2   (end excluded, like slicing)
    ...
for i, word in enumerate(["a", "b"]):   # index and value together
    ...
while n != 1:                # when you don't know how many steps
    ...
```
Truthiness: `""`, `0`, `[]`, `{}` and `None` are false, and everything else is true. So `if not name:` catches both `""` and `None`.

## Functions: `return` vs `print`
```python
def total(qty, price, vat=0.22):        # vat has a default
    """Price including VAT."""
    return qty * price * (1 + vat)      # gives the value back to the caller

x = total(2, 10)          # 24.4
y = print(total(2, 10))   # prints 24.4, but y is None
```
`print` shows something to a human. `return` hands a value to the next piece of code. Tests check returns.

## Worked example (do the same for `count_vowels`)
"Count words longer than 3 letters":
```python
def count_long_words(text):
    count = 0                    # 1. an accumulator
    for word in text.split():    # 2. loop over pieces
        if len(word) > 3:        # 3. a condition
            count += 1           # 4. update
    return count                 # 5. return after the loop, not inside it
```
Most of this week's exercises follow this accumulator pattern.

> **Remember**
> - `=` assigns, `==` compares.
> - Indentation is syntax: 4 spaces. The body of `if`/`for`/`def` is indented.
> - `range(a, b)` and `s[a:b]` exclude `b`.
> - Strings never change in place: `s.upper()` returns a new string.
> - A function without `return` returns `None`.
