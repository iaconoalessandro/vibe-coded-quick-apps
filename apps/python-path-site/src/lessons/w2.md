## Why this week exists
Data engineering in plain Python is mostly **moving rows between lists and dicts**. The DSS project bans pandas, so `dict` and `list` *are* your dataframe. Get this week right and the project becomes plumbing.

## The four containers
| | literal | mutable | ordered | `x in` cost | use for |
|---|---|---|---|---|---|
| list | `[1, 2]` | yes | yes | O(n) | sequences, rows |
| tuple | `(1, 2)` | no | yes | O(n) | fixed records, dict keys |
| dict | `{"a": 1}` | yes | insertion | **O(1)** | lookup by key, grouping |
| set | `{1, 2}` | yes | no | **O(1)** | distinct values, "seen before?" |

## Aliasing: the bug that eats afternoons
```python
a = [1, 2]
b = a          # NOT a copy: two names, one list
b.append(3)
a              # [1, 2, 3]
c = a.copy()   # a real (shallow) copy; nested lists still shared -> copy.deepcopy
```
Functions receive the same object, so a function that `.append`s to its argument changes the caller's list.

## A table = a list of dicts
```python
rows = [
    {"user": "u1", "hour": 22, "likes": 10},
    {"user": "u2", "hour": 9,  "likes": 3},
    {"user": "u1", "hour": 23, "likes": 7},
]
# GROUP BY user, SUM(likes)
totals = {}
for r in rows:
    totals[r["user"]] = totals.get(r["user"], 0) + r["likes"]
# {'u1': 17, 'u2': 3}

from collections import defaultdict, Counter
by_user = defaultdict(list)
for r in rows:
    by_user[r["user"]].append(r)          # group whole rows
Counter(r["user"] for r in rows)          # Counter({'u1': 2, 'u2': 1})
```

## Comprehensions and sorting
```python
[r["likes"] for r in rows if r["hour"] >= 20]            # [10, 7]
{r["user"] for r in rows}                                  # {'u1', 'u2'}
sorted(rows, key=lambda r: (-r["likes"], r["user"]))       # likes desc, then user
```
`sorted()` returns a new list. `list.sort()` sorts in place and returns `None`.

## Recursion, Python edition
You know the theory. In Python:
```python
def total_size(folder):              # folder = {"files": [3, 5], "subfolders": [...]}
    return sum(folder["files"]) + sum(total_size(f) for f in folder["subfolders"])
```
Python stops at about 1000 nested calls (`RecursionError`), so use recursion for trees and divide-and-conquer, and loops for long sequences. The P4DS exam always asks for one recursive function.

> **Remember**
> - Need "have I seen this?" inside a loop? Use a **set**, never a list.
> - `b = a` doesn't copy. `a.copy()` does (shallowly).
> - Dict keys must be hashable: tuples yes, lists no.
> - `d[k]` raises KeyError. `d.get(k, default)` doesn't.
> - Don't add or remove items in a list while looping over it. Build a new one.
